# JobTracker

## About the Project

JobTracker is a web application designed to help users organize and track their job applications in one place. Users can keep track of the positions they apply for, monitor interview progress, and update application statuses.

I developed this project as part of my web development coursework to practice building websites using HTML, CSS, and JavaScript.

## Features

- Track job applications in one place.
- Record job positions and company information.
- Monitor application statuses, such as Applied, Interviewing, Waiting for Results, and Rejected.
- Organize job search progress through a simple user interface.

## Technologies Used

- HTML
- CSS
- JavaScript

## Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
